# 規格書：撲克手牌速記 v1

> 本文件是開發的唯一依據。規格要改先改這裡。

## 1. 目標

在實體錦標賽（MTT）現場，一手結束到下一手發牌前的空檔，**step by step 快速記下一手牌的流程**（誰下注、加注、蓋牌）；之後**一鍵把文字傳到 LINE** 給朋友討論。

原則：**簡單、快速、好用**。手機版為主。

## 2. 範圍

### v1 做

- 記一手：位置、手牌、**每條街的行動（蓋牌 / 過牌 / 跟 / 下注 / 加注 / 全下）**、公牌、籌碼（bb）、結果（bb）、備註、★ 要討論
- 一個畫面做完，上方步驟列可以隨時切換到任何一步
- 手牌列表（依日期分組），點進去可以補寫、修改、刪除
- **複製成文字**、**傳到 LINE**
- 每次輸入即時存檔（只存本機）
- PWA：離線可用、加到主畫面
- 部署 Vercel

### 之後再說（上線後依需要加）

常見情境一鍵套用（例如「我開被跟」）、攤牌記對手的牌、待補完篩選、CSV 匯出、標籤。

### 不做

賽事 / 場次、盲注與升盲、統計、雲端同步、帳號、勝率計算、匯入、單挑（2 人桌）的特殊順序。

## 3. 頁面

| 路由 | 頁面 |
|---|---|
| `/` | 手牌列表 |
| `/hand/:id` | 一手牌（記一手和補寫是同一頁） |

按「記一手」時先產生新 id 並進入 `/hand/:id`；**第一次有輸入才寫進資料庫**，什麼都沒填就離開不會留下空白紀錄。新的一手沿用上一手的人數和 BBA 設定。

### 3.1 手牌列表 `/`

- 依日期分組（今天、昨天、`10/12 (六)`），新的在上面。
- 每列：時間、位置、手牌、公牌、籌碼、結果、★；第二行是備註第一行（截斷）。
- 點一列進入該手。
- **底部固定大按鈕「記一手」**（滿寬、至少 56px 高、在拇指範圍內）。
- 沒資料時顯示簡短說明。
- 提示橫幅（最多一個）：LINE 內建瀏覽器提示 → iOS 加到主畫面引導 → 有新版本。

### 3.2 一手牌 `/hand/:id`：一個畫面、隨時切換步驟

整頁固定一個螢幕高，不捲動（只有中間的摘要區可以捲）。由上而下：

```
 ←   10/15 (四) 21:34          ★  🗑
 位置 手牌 翻前 翻牌 轉牌 河牌 結果 備註   ← 步驟列
  ✓    ✓    •    ○    ○    ○    ○    ○
 ─────────────────────────────
 位置  BTN  9 人桌 · BBA                 ← 摘要：整手的流程
 手牌  A♠K♦                                 點一行跳到那一步
 翻前  [CO 開 2.2] [Hero 3bet 7]            點一個行動可以修改
 ─────────────────────────────
 這一步的輸入區（固定在下半部）             ← 選牌 / 行動 / 數字
 ─────────────────────────────
 [＋ 下一手]   [複製]   [傳到 LINE]
```

**步驟**：位置 → 手牌 → 翻前 → 翻牌 → 轉牌 → 河牌 → 結果 → 備註。

- 步驟列的記號：✓ 記好了、• 記了一部分、○ 還沒記、– 這手在前面就結束了（用不到）。
- 任何一步都可以直接點過去。打開一手時停在第一個還沒記完的步驟。
- **自動往下**：
  - 選好位置 → 手牌
  - 兩張手牌選完 → 翻前
  - 一條街的行動結束 → 下一條街（先選公牌，再記行動）
  - 大家蓋牌結束 → 結果
  - 全下後沒人能再行動 → 把剩下的公牌選完 → 結果
  - 結果 → 備註
- **輸入區**依步驟換內容：
  - 位置：人數（3–9）、BBA、我的籌碼、位置按鈕
  - 手牌：兩個牌格 + 選牌鍵盤
  - 翻前～河牌：這條街的公牌 + 底池 + 復原，下面是選牌鍵盤（公牌還沒選）或行動按鈕
  - 結果：數字鍵盤（輸 / 贏）
  - 備註：多行文字 + ★ 要討論
- **跳步驟的規則**：
  1. 牌隨時可以改，不影響其他東西。
  2. 從摘要點一個行動：
     - 「改金額」：只改金額，底池自動重算，後面的行動保留。改了之後後面接不上，先問過再清掉接不上的部分。
     - 「從這裡重記」：清掉這個行動和之後的（要確認），回到那條街重記。
  3. 前面的街還沒記完就點後面的街：可以「回到前一條街」，或「直接從這條街開始記」：點選還在牌局的人，前面的街就當作沒記細節（底池不知道）。
  4. 已經記完的街：顯示「記完了」，可以「從這條街重記」。
  5. 「復原」拿掉最後一個行動；復原到前一條街，畫面就跟著回去。

**即時存檔**：每次輸入都直接寫進 IndexedDB，包括備註每打一個字（資料很小，寫入很便宜）。不做 debounce，所以鎖屏、切 App、關掉頁面都沒有「還沒存」的空窗。

## 4. 輸入元件

### 4.1 選牌鍵盤

```
 翻牌 2/3                        清除  跳過
  A   K   Q   J   T   9   8
  7   6   5   4   3   2
   ♠      ♥      ♦      ♣
```

- **兩下一張**：點數 + 花色，先按哪個都可以。
- **不可能重複**：這手已經用過的牌反灰不能點。
- **填滿自動跳下一格**，這一步的牌格都填好就自動往下一步。
- **清除**目前這格；**跳過**這格（留空）。這次記錄中跳過的步驟，回來時不會再自動跳出選牌，點牌格才會。
- 點已經有牌的格子 → 替換那張牌。
- 按鍵至少 48px 高。

### 4.2 位置與人數

| 人數 | 位置（翻前行動順序） |
|---|---|
| 9 | UTG、UTG+1、UTG+2、LJ、HJ、CO、BTN、SB、BB |
| 8 | UTG、UTG+1、LJ、HJ、CO、BTN、SB、BB |
| 7 | UTG、LJ、HJ、CO、BTN、SB、BB |
| 6 | UTG、HJ、CO、BTN、SB、BB |
| 5 | HJ、CO、BTN、SB、BB |
| 4 | CO、BTN、SB、BB |
| 3 | BTN、SB、BB |

翻後順序是 SB、BB 先，BTN 最後。再點一次已選的位置 = 取消。已經記了行動再改人數，要確認並清掉行動。

### 4.3 行動按鈕

```
 UTG   UTG+1  UTG+2   LJ    HJ       ← 已蓋牌（灰）
 [CO]  BTN    SB      BB             ← 輪到的人亮起來
 輪到 CO 要跟到 7bb      點後面的位置 = 中間都蓋牌
 [ 蓋牌 ] [ 跟 ] [ 加注 ] [ 全下 ]
```

- App 依規則判斷輪到誰、可不可以過牌、這條街什麼時候結束、底池多少。
- **點後面的位置 = 中間還沒行動的人都蓋牌**（大部分人都是直接蓋，不用一個個按）。
- 沒有人下注時是「過牌 / 下注」，有人下注時是「跟 / 加注」。
- 翻後只列還在牌局的人。
- **加注 / 下注 / 全下**跳出金額輸入（bb）：
  - 常用尺寸一鍵確定：開局 2 / 2.2 / 2.5 / 3（有人跛入是 3 / 4 / 5 / 6）；面對加注 ×2.5 / ×3 / ×4；翻後下注 ⅓、½、⅔ 池、滿池。
  - Hero 全下時有「我的籌碼」可以一鍵帶入。
  - 不知道金額可以留空直接確定（之後底池就顯示不出來）。
  - 下注 / 加注金額要大於現在要跟的數字。
- 全下金額小於要跟的數字 = 全下跟注，不會讓別人重新行動。

### 4.4 數字鍵盤（bb）

1–9、0、小數點、倒退；小數最多一位。結果用「輸 −」「贏 +」決定正負並確定；籌碼只有「確定」。都有「清除」。

## 5. 分享文字

```
Hero BTN A♠K♦(25bb)
翻前：CO 開 2.2bb，Hero 3bet 7bb，CO 跟
翻牌 K♣7♦2♠（底池 16.5bb）：CO 過牌，Hero 下注 5bb，CO 跟
轉牌 9♥（底池 26.5bb）：CO 過牌，Hero 全下 13bb，CO 蓋牌
結果 +13.5bb

這裡推是不是太激進?
```

- 翻前沒投過錢的人蓋牌不列出；翻後的蓋牌都列。
- 加注的叫法：翻前第一次加注是「開」（有人跛入就是「加注到」），之後是 3bet、4bet…；翻後是「下注」、「加注到」。
- 沒記行動時，公牌合成一行「公牌 K♣7♦2♠ 9♥ 2♦」。
- 沒資料的部分省略；空的牌格不顯示；底池不知道就不寫。
- bb 整數不帶小數，否則一位小數；結果正數帶 `+`。
- 花色用 ♠♥♦♣ 文字符號。備註原樣接在後面，前面空一行。不含日期時間。

## 6. 視覺

- 預設深色主題。
- **四色牌**：♠ 黑、♥ 紅、♦ 藍、♣ 綠。牌畫成**淺色牌面上的彩色花色**，所以深色背景下黑桃也清楚。花色用內嵌 SVG，不用 emoji 或文字符號。
- 系統字型，不載入網路字型。
- 行動按鈕顏色固定：蓋牌灰、跟 / 過牌綠、加注 / 下注琥珀、全下紅。
- 正的結果綠色、負的紅色。

## 7. 資料模型

```ts
type Card = `${Rank}${Suit}`             // 'As'、'Td'
type Position = 'UTG'|'UTG+1'|'UTG+2'|'LJ'|'HJ'|'CO'|'BTN'|'SB'|'BB'

type Action =
  | { seat: Position; type: 'fold'|'check'|'call'|'bet'|'raise'|'allin'; to: number | null; auto?: boolean }
  | { type: 'street'; street: 1 | 2 | 3; live: Position[] }   // 前面沒記完，直接從這條街開始

interface Hand {
  id: string
  schemaVersion: 2
  tableSize: 3 | 4 | 5 | 6 | 7 | 8 | 9
  bbAnte: boolean                        // 大盲前注 1bb，只影響底池
  position: Position | null
  hero: (Card | null)[]                  // 固定 2 格
  board: (Card | null)[]                 // 固定 5 格：翻牌 3、轉牌、河牌
  actions: Action[]                      // 依時間順序
  stackBb: number | null
  resultBb: number | null
  note: string
  starred: boolean
  createdAt: number                      // 這手的時間
  updatedAt: number
}
```

- `to` 是下注 / 加注 / 全下「加到多少」（這條街的總額，bb）；不知道是 null。`auto` 是「點後面的位置」自動補的蓋牌，復原時整組一起拿掉。
- 行動只存原始順序；輪到誰、底池、每條街的分段、「開 / 3bet」這些說明都由 `lib/actions.ts` 的 `replay()` 重播算出來，不存。
- 讀到舊版（schemaVersion 1，沒有人數、BBA、行動）的資料時補上預設值（9 人、BBA、沒有行動）。
- Dexie：`db.version(1).stores({ hands: 'id, createdAt' })`。之後加欄位不需要改索引；要改索引就加 `version(2)` 並寫 `upgrade()`。

## 8. 本機儲存的風險

資料只在這台手機的這個 App 裡，沒有雲端、沒有匯入。對策：

1. **一定要加到主畫面**。iPhone Safari 會清掉 7 天沒開過的網站資料，加到主畫面的 App 不受影響。
2. **iOS 上 Safari 和主畫面 App 的資料是分開的**，在 Safari 記的不會跟到主畫面 App。所以在 iOS Safari（非主畫面模式）打開時，首頁顯示「先加到主畫面再開始記」的引導。
3. **LINE 內建瀏覽器**：偵測 User-Agent 含 `Line/` 時提示，提供加上 `openExternalBrowser=1` 的連結改用外部瀏覽器開。
4. 啟動時呼叫 `navigator.storage.persist()`。

## 9. 手機細節

- `viewport-fit=cover`，用 `env(safe-area-inset-*)` 處理瀏海與底部橫條；高度用 `dvh`。
- 全站 `touch-action: manipulation`；`overscroll-behavior: none`。
- 輸入框、下拉選單字級至少 16px（iOS 才不會自動放大）。
- 主要按鈕在畫面下半部，觸控目標至少 44–48px。
- 電腦上就是置中的手機寬度欄（最寬 480px）。
- `crypto.randomUUID()` 和 Clipboard API 只在 HTTPS / localhost 可用；用手機連區網 IP 測試時要有替代做法。

## 10. PWA 與部署

- vite-plugin-pwa：預先快取全部靜態檔，離線可用；有新版本時顯示「有新版本，點這裡更新」，不自動重新整理。
- manifest：名稱「撲克速記」、`display: standalone`、`orientation: portrait`、深色主題色、192 / 512 / maskable icon、iOS `apple-touch-icon`。
- Vercel：純靜態，`pnpm build` 輸出 `dist/`，`vercel.json` 把所有路徑 rewrite 到 `/index.html`。push 到 `main` 就上線；其他分支有預覽網址。

## 11. 技術

Vite + React + TypeScript、Tailwind CSS v4、React Router、Dexie.js + `useLiveQuery`、vite-plugin-pwa、Vitest、pnpm、Vercel。
