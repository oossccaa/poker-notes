# 規格書：撲克手牌速記 v1

> 本文件是開發的唯一依據。規格要改先改這裡。

## 1. 目標

在實體錦標賽（MTT）現場，一手結束到下一手發牌前的空檔，**快速記下一手牌**；之後**一鍵把文字傳到 LINE** 給朋友討論。

原則：**簡單、快速、好用**。手機版為主。

## 2. 範圍

### v1 做（先上線的最小版本）

- 記一手：位置、手牌、公牌、籌碼（bb）、結果（bb）、備註、★ 要討論
- 手牌列表（依日期分組），點進去可以補寫、修改、刪除
- **複製成文字**、**傳到 LINE**
- 每次輸入即時存檔（只存本機）
- PWA：離線可用、加到主畫面
- 部署 Vercel

### 之後再說（上線後依需要加）

每條街分開記行動、攤牌、待補完篩選、CSV 匯出、標籤。

### 不做

賽事 / 場次、盲注與升盲、統計、雲端同步、帳號、勝率計算、匯入。

## 3. 頁面

| 路由 | 頁面 |
|---|---|
| `/` | 手牌列表 |
| `/hand/:id` | 一手牌（記一手和補寫是同一頁） |

按「記一手」時先產生新 id 並進入 `/hand/:id`；**第一次有輸入才寫進資料庫**，什麼都沒填就離開不會留下空白紀錄。

### 3.1 手牌列表 `/`

- 依日期分組（今天、昨天、`10/12 (六)`），新的在上面。
- 每列：時間、位置、手牌、公牌、籌碼、結果、★；第二行是備註第一行（截斷）。
- 點一列進入該手。
- **底部固定大按鈕「記一手」**（滿寬、至少 56px 高、在拇指範圍內）。
- 沒資料時顯示簡短說明。
- 提示橫幅（最多一個）：LINE 內建瀏覽器提示 → iOS 加到主畫面引導 → 有新版本。

### 3.2 一手牌 `/hand/:id`

由上而下：

1. **頂列**：← 返回、時間、★ 切換、刪除（要確認）
2. **位置**：9 顆按鈕（見 4.2）。選好位置、且手牌還沒填時，自動打開選牌鍵盤。
3. **手牌**：兩格
4. **公牌**：翻牌三格、轉牌、河牌
5. **籌碼 / 結果**：兩個並排的格子，點開數字鍵盤，單位都是 bb
6. **備註**：多行文字，自由寫過程、對手、想問的問題

**底部固定列**：`＋ 下一手`｜`複製`｜`傳到 LINE`

- **下一手**：直接開新的一手（現場最常用）。
- **複製**：把分享文字複製到剪貼簿，顯示「已複製」。
- **傳到 LINE**：開啟 `https://line.me/R/share?text=…`，直接在 LINE 選朋友或群組。

**即時存檔**：每次輸入都直接寫進 IndexedDB，包括備註每打一個字（資料很小，寫入很便宜）。不做 debounce，所以鎖屏、切 App、關掉頁面都沒有「還沒存」的空窗。

## 4. 輸入元件

### 4.1 選牌鍵盤（產品核心）

從底部滑出的面板，像手機鍵盤。上方的牌格仍然看得到，目前要填的格子要明顯標示。

```
┌─────────────────────────────────┐
│ 翻牌 2/3        清除  跳過  收起 │
├─────────────────────────────────┤
│  A   K   Q   J   T   9   8      │
│  7   6   5   4   3   2          │
├─────────────────────────────────┤
│   ♠      ♥      ♦      ♣       │
└─────────────────────────────────┘
```

- **兩下一張**：點數 + 花色，先按哪個都可以。
- **不可能重複**：這手已經用過的牌反灰不能點（已選點數 → 用過的花色反灰；已選花色 → 用過的點數反灰；四種花色都用過的點數永遠反灰）。
- **填滿自動跳下一格**：手牌 1 → 手牌 2 → 翻牌 1 → 2 → 3 → 轉牌 → 河牌，河牌填完自動收起。
- **清除**目前這格、**跳過**這格（留空）、**收起**面板。
- 點已經有牌的格子 → 替換那張牌。
- 點數鍵排兩列（7 + 6），花色鍵一列；按鍵至少 48px 高。
- 整手 7 張牌最多 14 下。

### 4.2 位置

固定 9 顆，依翻前行動順序：`UTG` `UTG+1` `UTG+2` `LJ` `HJ` / `CO` `BTN` `SB` `BB`。
不分桌型（8 人桌就不用 UTG+2）。再點一次已選的位置 = 取消。

### 4.3 數字鍵盤（bb）

底部面板，不叫出系統鍵盤。

```
┌──────────────────────────────┐
│ 結果                 27.5 bb │
├──────────────────────────────┤
│   1      2      3      ⌫     │
│   4      5      6      清除   │
│   7      8      9            │
│   .      0                   │
├──────────────────────────────┤
│   [ 輸 − ]      [ 贏 + ]     │
└──────────────────────────────┘
```

- 小數最多一位。
- **結果**：按「輸 −」或「贏 +」決定正負並確定。0 = 平手。
- **籌碼**：只有一顆「確定」。
- **清除**：把這個欄位設回空白。
- 點面板外 = 取消，不改值。

## 5. 分享文字

```
Hero BTN A♠K♦(25bb)
公牌 K♣7♦2♠ 9♥ 2♦
結果 +27.5bb

CO 開 2.2bb,我直接推,CO 想很久跟了 QQ
這裡推是不是太激進?
```

- 沒資料的部分省略：沒位置就不寫位置，沒公牌就沒有「公牌」那行，沒結果就沒有「結果」那行。
- 空的牌格不顯示。
- bb 整數不帶小數，否則一位小數；正數帶 `+`。
- 花色用 ♠♥♦♣ 文字符號。
- 備註原樣接在後面，前面空一行。
- 不含日期時間。

## 6. 視覺

- 預設深色主題。
- **四色牌**：♠ 黑、♥ 紅、♦ 藍、♣ 綠。牌畫成**淺色牌面上的彩色花色**，所以深色背景下黑桃也清楚。花色用內嵌 SVG，不用 emoji 或文字符號。
- 系統字型，不載入網路字型。
- 正的結果綠色、負的紅色。

## 7. 資料模型

```ts
type Rank = 'A'|'K'|'Q'|'J'|'T'|'9'|'8'|'7'|'6'|'5'|'4'|'3'|'2'
type Suit = 's'|'h'|'d'|'c'
type Card = `${Rank}${Suit}`             // 'As'、'Td'
type Position = 'UTG'|'UTG+1'|'UTG+2'|'LJ'|'HJ'|'CO'|'BTN'|'SB'|'BB'

interface Hand {
  id: string
  schemaVersion: 1
  position: Position | null
  hero: (Card | null)[]                  // 固定 2 格
  board: (Card | null)[]                 // 固定 5 格：翻牌 3、轉牌、河牌
  stackBb: number | null
  resultBb: number | null
  note: string
  starred: boolean
  createdAt: number                      // epoch ms，也就是這手的時間
  updatedAt: number
}
```

Dexie：

```ts
db.version(1).stores({ hands: 'id, createdAt' })
```

- 牌格固定長度、空格用 `null`，「跳過」的格子不會讓後面的牌往前移。
- 同一手的牌不能重複，由選牌鍵盤保證，`src/lib/cards.ts` 也有檢查函式。
- 之後加欄位（例如每條街的行動）不需要改索引；要改索引就加 `version(2)` 並寫 `upgrade()`。

## 8. 本機儲存的風險

資料只在這台手機的這個 App 裡，沒有雲端、沒有匯入。對策：

1. **一定要加到主畫面**。iPhone Safari 會清掉 7 天沒開過的網站資料，加到主畫面的 App 不受影響。
2. **iOS 上 Safari 和主畫面 App 的資料是分開的**，在 Safari 記的不會跟到主畫面 App。所以在 iOS Safari（非主畫面模式）打開時，首頁顯示「先加到主畫面再開始記」的引導：分享 → 加入主畫面。
3. **LINE 內建瀏覽器**：從 LINE 點連結會開在 LINE 裡，加不了主畫面。偵測 User-Agent 含 `Line/` 時提示，提供加上 `openExternalBrowser=1` 的連結改用外部瀏覽器開。
4. 啟動時呼叫 `navigator.storage.persist()`。

## 9. 手機細節

- `viewport-fit=cover`，用 `env(safe-area-inset-*)` 處理瀏海與底部橫條；高度用 `dvh`。
- 全站 `touch-action: manipulation`；`overscroll-behavior: none`。
- 輸入框字級至少 16px。
- 主要按鈕在畫面下半部，觸控目標至少 48px。
- 電腦上就是置中的手機寬度欄（最寬 480px）。
- `crypto.randomUUID()` 和 Clipboard API 只在 HTTPS / localhost 可用；用手機連區網 IP 測試時要有替代做法。

## 10. PWA 與部署

- vite-plugin-pwa：預先快取全部靜態檔，離線可用；有新版本時顯示「有新版本，點這裡更新」，不自動重新整理。
- manifest：名稱「撲克速記」、`display: standalone`、`orientation: portrait`、深色主題色、192 / 512 / maskable icon、iOS `apple-touch-icon`。
- Vercel：純靜態，`pnpm build` 輸出 `dist/`，`vercel.json` 把所有路徑 rewrite 到 `/index.html`。

## 11. 技術

Vite + React + TypeScript、Tailwind CSS v4、React Router、Dexie.js + `useLiveQuery`、vite-plugin-pwa、Vitest、pnpm、Vercel。
